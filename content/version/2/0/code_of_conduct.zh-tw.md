# 貢獻者契約行為準則

## 我們的承諾

作為會員、貢獻者和領導者，我們承諾讓每個人在參與我們的社區時都獲得無騷擾的體驗，無論年齡、體型、有形或無形的殘疾、種族、性別特徵、性別認同和表達、經驗水平、教育程度、社會經濟地位、國籍、外表、種族、宗教或性認同和取向。

我們承諾以有助於建立開放、熱情、多元化、包容和健康社區的方式行事和互動。

## 我們的標準

有助於為我們的社區創造正向環境的行為範例包括：

* 對他人表現出同理心和友善
* 尊重不同的意見、觀點和經驗
* 提供並優雅地接受建設性回饋
* 承擔責任並向受我們的錯誤影響的人道歉，並從經驗中學習
* 關注不僅對我們個人最有利，而且對整個社區最有利的事情

不可接受的行為範例包括：

* 使用性語言或圖像，以及任何形式的性關注或挑逗
* 惡搞、侮辱或貶損評論以及人身或政治攻擊
* 公開或私人騷擾
* 未經他人明確許可，發布他人的私人訊息，例如實際地址或電子郵件地址
* 在專業環境中可能被合理地認為不適當的其他行為

## 執法責任

社區領袖有責任澄清和執行我們可接受的行為標準，並將採取適當和公平的糾正措施，以應對他們認為不適當、威脅、冒犯或有害的任何行為。

社群領導者有權利和責任刪除、編輯或拒絕不符合本行為準則的評論、提交、代碼、維基編輯、問題和其他貢獻，並將在適當的時候傳達審核決定的原因。

## 範圍

本行為準則適用於所有社區空間，也適用於個人在公共場所正式代表社區的情況。代表我們社群的範例包括使用官方電子郵件地址、透過官方社群媒體帳號發佈或在線上或線下活動中擔任指定代表。

## 執行

辱罵、騷擾或其他不可接受的行為可以透過 [插入聯絡方式] 向負責執行的社群領導報告。所有投訴都將得到及時、公正的審查和調查。

所有社區領導者都有義務尊重任何事件報告者的隱私和安全。

## 執行指引

社群領袖將遵循這些社群影響準則來確定他們認為違反本行為準則的任何行為的後果：

### 1. 修正

**社群影響**：使用不當語言或其他被社群視為不專業或不受歡迎的行為。

**後果**：來自社區領袖的私下書面警告，明確違規行為的性質，並解釋為何該行為不當。可能會要求公開道歉。

### 2. 警告

**社群影響**：透過單一事件或一系列行為造成的違規行為。

**後果**：針對持續行為的後果的警告。在指定時間內不與相關人員互動，包括主動與執行行為準則的人員互動。這包括避免在社區空間以及社交媒體等外部管道中進行互動。違反這些條款可能會導致暫時或永久禁令。

### 3. 臨時禁令

**社區影響**：嚴重違反社區標準，包括持續的不當行為。

**後果**：在指定時間內暫時禁止與社區進行任何形式的互動或公共溝通。在此期間，不得與相關人員進行公開或私下互動，包括主動與行為準則執行人員互動。違反這些條款可能會導致永久禁令。

### 4. 永久封禁

**社群影響**：展示違反社群標準的模式，包括持續的不當行為、騷擾個人或攻擊或貶低個人類別。

**後果**：永久禁止社區內任何形式的公共互動。
