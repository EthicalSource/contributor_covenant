# ಕೊಡುಗೆದಾರರ ನೀತಿ ಸಂಹಿತೆ

ಈ ಪ್ರಾಜೆಕ್ಟ್‌ನ ಕೊಡುಗೆದಾರರು ಮತ್ತು ನಿರ್ವಾಹಕರು ಮತ್ತು ಮುಕ್ತ ಮತ್ತು ಸ್ವಾಗತಾರ್ಹ ಸಮುದಾಯವನ್ನು ಬೆಳೆಸುವ ಆಸಕ್ತಿಯಲ್ಲಿ, ಸಮಸ್ಯೆಗಳನ್ನು ವರದಿ ಮಾಡುವುದು, ವೈಶಿಷ್ಟ್ಯದ ವಿನಂತಿಗಳನ್ನು ಪೋಸ್ಟ್ ಮಾಡುವುದು, ದಸ್ತಾವೇಜನ್ನು ನವೀಕರಿಸುವುದು, ಪುಲ್ ವಿನಂತಿಗಳು ಅಥವಾ ಪ್ಯಾಚ್‌ಗಳನ್ನು ಸಲ್ಲಿಸುವುದು ಮತ್ತು ಇತರ ಚಟುವಟಿಕೆಗಳ ಮೂಲಕ ಕೊಡುಗೆ ನೀಡುವ ಎಲ್ಲ ಜನರನ್ನು ಗೌರವಿಸಲು ನಾವು ಪ್ರತಿಜ್ಞೆ ಮಾಡುತ್ತೇವೆ.

ಅನುಭವದ ಮಟ್ಟ, ಲಿಂಗ, ಲಿಂಗ ಗುರುತಿಸುವಿಕೆ ಮತ್ತು ಅಭಿವ್ಯಕ್ತಿ, ಲೈಂಗಿಕ ದೃಷ್ಟಿಕೋನ, ಅಂಗವೈಕಲ್ಯ, ವೈಯಕ್ತಿಕ ನೋಟ, ದೇಹದ ಗಾತ್ರ, ಜನಾಂಗ, ಜನಾಂಗ, ವಯಸ್ಸು, ಧರ್ಮ ಅಥವಾ ರಾಷ್ಟ್ರೀಯತೆಯನ್ನು ಲೆಕ್ಕಿಸದೆ, ಈ ಯೋಜನೆಯಲ್ಲಿ ಭಾಗವಹಿಸುವಿಕೆಯನ್ನು ಎಲ್ಲರಿಗೂ ಕಿರುಕುಳ-ಮುಕ್ತ ಅನುಭವವನ್ನಾಗಿ ಮಾಡಲು ನಾವು ಬದ್ಧರಾಗಿದ್ದೇವೆ.

ಭಾಗವಹಿಸುವವರ ಸ್ವೀಕಾರಾರ್ಹವಲ್ಲದ ನಡವಳಿಕೆಯ ಉದಾಹರಣೆಗಳು:

* ಲೈಂಗಿಕ ಭಾಷೆ ಅಥವಾ ಚಿತ್ರಣದ ಬಳಕೆ
* ವೈಯಕ್ತಿಕ ದಾಳಿಗಳು
* ಟ್ರೋಲಿಂಗ್ ಅಥವಾ ಅವಮಾನಕರ/ ಅವಹೇಳನಕಾರಿ ಕಾಮೆಂಟ್‌ಗಳು
* ಸಾರ್ವಜನಿಕ ಅಥವಾ ಖಾಸಗಿ ಕಿರುಕುಳ
* ಸ್ಪಷ್ಟ ಅನುಮತಿಯಿಲ್ಲದೆ ಭೌತಿಕ ಅಥವಾ ಎಲೆಕ್ಟ್ರಾನಿಕ್ ವಿಳಾಸಗಳಂತಹ ಇತರರ ಖಾಸಗಿ ಮಾಹಿತಿಯನ್ನು ಪ್ರಕಟಿಸುವುದು
* ಇತರ ಅನೈತಿಕ ಅಥವಾ ವೃತ್ತಿಪರವಲ್ಲದ ನಡವಳಿಕೆ

ಈ ನೀತಿ ಸಂಹಿತೆಗೆ ಹೊಂದಿಕೆಯಾಗದ ಕಾಮೆಂಟ್‌ಗಳು, ಬದ್ಧತೆಗಳು, ಕೋಡ್, ವಿಕಿ ಸಂಪಾದನೆಗಳು, ಸಮಸ್ಯೆಗಳು ಮತ್ತು ಇತರ ಕೊಡುಗೆಗಳನ್ನು ತೆಗೆದುಹಾಕಲು, ಸಂಪಾದಿಸಲು ಅಥವಾ ತಿರಸ್ಕರಿಸಲು ಪ್ರಾಜೆಕ್ಟ್ ನಿರ್ವಾಹಕರು ಹಕ್ಕು ಮತ್ತು ಜವಾಬ್ದಾರಿಯನ್ನು ಹೊಂದಿರುತ್ತಾರೆ ಅಥವಾ ಅವರು ಸೂಕ್ತವಲ್ಲದ, ಬೆದರಿಕೆ, ಆಕ್ರಮಣಕಾರಿ ಅಥವಾ ಹಾನಿಕಾರಕವೆಂದು ಭಾವಿಸುವ ಇತರ ನಡವಳಿಕೆಗಳಿಗೆ ಯಾವುದೇ ಕೊಡುಗೆದಾರರನ್ನು ತಾತ್ಕಾಲಿಕವಾಗಿ ಅಥವಾ ಶಾಶ್ವತವಾಗಿ ನಿಷೇಧಿಸುತ್ತಾರೆ.

ಈ ನೀತಿ ಸಂಹಿತೆಯನ್ನು ಅಳವಡಿಸಿಕೊಳ್ಳುವ ಮೂಲಕ, ಯೋಜನಾ ನಿರ್ವಾಹಕರು ಈ ಯೋಜನೆಯನ್ನು ನಿರ್ವಹಿಸುವ ಪ್ರತಿಯೊಂದು ಅಂಶಕ್ಕೂ ಈ ತತ್ವಗಳನ್ನು ನ್ಯಾಯಯುತವಾಗಿ ಮತ್ತು ಸ್ಥಿರವಾಗಿ ಅನ್ವಯಿಸಲು ತಮ್ಮನ್ನು ತಾವು ಬದ್ಧರಾಗಿರುತ್ತಾರೆ. ನೀತಿ ಸಂಹಿತೆಯನ್ನು ಅನುಸರಿಸದ ಅಥವಾ ಜಾರಿಗೊಳಿಸದ ಪ್ರಾಜೆಕ್ಟ್ ನಿರ್ವಾಹಕರನ್ನು ಪ್ರಾಜೆಕ್ಟ್ ತಂಡದಿಂದ ಶಾಶ್ವತವಾಗಿ ತೆಗೆದುಹಾಕಬಹುದು.

ಒಬ್ಬ ವ್ಯಕ್ತಿಯು ಪ್ರಾಜೆಕ್ಟ್ ಅಥವಾ ಅದರ ಸಮುದಾಯವನ್ನು ಪ್ರತಿನಿಧಿಸುತ್ತಿರುವಾಗ ಈ ನೀತಿ ಸಂಹಿತೆಯು ಯೋಜನಾ ಸ್ಥಳಗಳಲ್ಲಿ ಮತ್ತು ಸಾರ್ವಜನಿಕ ಸ್ಥಳಗಳಲ್ಲಿ ಎರಡೂ ಅನ್ವಯಿಸುತ್ತದೆ.
