# ફાળો આપનારની આચારસંહિતા

આ પ્રોજેક્ટના યોગદાનકર્તાઓ અને જાળવણીકારો તરીકે, અને ખુલ્લા અને સ્વાગત સમુદાયને પ્રોત્સાહન આપવાના હિતમાં, અમે એવા તમામ લોકોનો આદર કરવાની પ્રતિજ્ઞા કરીએ છીએ જેઓ સમસ્યાઓની જાણ કરવા, વિશેષતા વિનંતીઓ પોસ્ટ કરવા, દસ્તાવેજીકરણ અપડેટ કરવા, પુલ વિનંતીઓ અથવા પેચ સબમિટ કરવા અને અન્ય પ્રવૃત્તિઓ દ્વારા યોગદાન આપે છે.

અનુભવના સ્તર, લિંગ, લિંગ ઓળખ અને અભિવ્યક્તિ, જાતીય અભિગમ, અપંગતા, વ્યક્તિગત દેખાવ, શરીરનું કદ, જાતિ, વંશીયતા, ઉંમર, ધર્મ અથવા રાષ્ટ્રીયતાને ધ્યાનમાં લીધા વિના, અમે આ પ્રોજેક્ટમાં સહભાગિતાને દરેક માટે પજવણી-મુક્ત અનુભવ બનાવવા માટે પ્રતિબદ્ધ છીએ.

સહભાગીઓ દ્વારા અસ્વીકાર્ય વર્તનનાં ઉદાહરણોમાં નીચેનાનો સમાવેશ થાય છે:

* લૈંગિક ભાષા અથવા છબીનો ઉપયોગ
* અંગત હુમલાઓ
* ટ્રોલિંગ અથવા અપમાનજનક/અપમાનજનક ટિપ્પણીઓ
* જાહેર અથવા ખાનગી સતામણી
* અન્યની ખાનગી માહિતી, જેમ કે ભૌતિક અથવા ઇલેક્ટ્રોનિક સરનામાંઓ, સ્પષ્ટ પરવાનગી વિના પ્રકાશિત કરવી
* અન્ય અનૈતિક અથવા અવ્યાવસાયિક આચરણ

પ્રોજેક્ટ જાળવણીકારો પાસે ટિપ્પણીઓ, પ્રતિબદ્ધતાઓ, કોડ, વિકિ સંપાદનો, મુદ્દાઓ અને અન્ય યોગદાનને દૂર કરવાનો, સંપાદિત કરવાનો અથવા નકારવાનો અધિકાર અને જવાબદારી છે જે આ આચાર સંહિતા સાથે જોડાયેલા નથી, અથવા અન્ય વર્તણૂકો માટે અસ્થાયી અથવા કાયમી ધોરણે કોઈપણ યોગદાનકર્તાને પ્રતિબંધિત કરવાનો અધિકાર અને જવાબદારી ધરાવે છે જેને તેઓ અયોગ્ય, ધમકીભર્યા, અપમાનજનક અથવા નુકસાનકારક માનતા હોય.

આ આચારસંહિતા અપનાવીને, પ્રોજેક્ટ જાળવણીકારો આ પ્રોજેક્ટના સંચાલનના દરેક પાસાઓ પર આ સિદ્ધાંતોને યોગ્ય અને સતત લાગુ કરવા માટે પ્રતિબદ્ધ છે. આચાર સંહિતાનું પાલન કે અમલ ન કરતા પ્રોજેક્ટ જાળવણીકારોને પ્રોજેક્ટ ટીમમાંથી કાયમી ધોરણે દૂર કરવામાં આવી શકે છે.

જ્યારે કોઈ વ્યક્તિ પ્રોજેક્ટ અથવા તેના સમુદાયનું પ્રતિનિધિત્વ કરતી હોય ત્યારે આ આચારસંહિતા પ્રોજેક્ટની જગ્યાઓ અને જાહેર જગ્યાઓ બંનેમાં લાગુ થાય છે.
