# Kolaboratzaileen Ituna 3.0 Jokabide Kodea

## Gure Konpromisoa

Gure komunitatea guztientzako abegikorra, segurua eta ekitatiboa izango dela konprometitzen dugu.

Pertsona guztien duintasuna, eskubideak eta ekarpenak errespetatuko eta sustatzen dituen ingurunea sustatzeko konpromisoa hartzen dugu, arraza, etnia, kasta, kolorea, adina, ezaugarri fisikoak, neuroaniztasuna, desgaitasuna, sexua edo generoa, genero identitatea edo adierazpena, sexu-orientazioa, hizkuntza, filosofia edo erlijioa, nazio- edo gizarte-maila, posizio nazional edo soziala, hezkuntza-maila, jatorri nazionala edo soziala, hezkuntza-maila, posizio nazionala edo soziala. Parte hartzeko pribilegio berberak zabaltzen zaizkie fede onez eta Itun honen arabera parte hartzen duten guztiei.

## Jokabide Sustatuak

Gizarte-arauetan dauden desberdintasunak aitortzen baditugu, guztiok ahalegintzen gara gure komunitateak jokabide positiboa izateko itxaropenak betetzen. Gainera, ulertzen dugu gure hitzak eta ekintzak kulturaren, jatorriaren edo jatorrizko hizkuntzaren arabera nahi duguna baino ezberdin interpreta daitezkeela.

Gogoeta hauek kontuan hartuta, ados gaude elkarren artean arretaz jokatzea eta gure balio partekatuak ardatz dituen moduan jardutea, besteak beste:

1. Gure komunitatearen **helburua**, gure jarduerak eta gure biltzeko moduak errespetatuz.
2. Besteekin **adeitasunez eta zintzotasunez** parte hartzea.
3. **Ikuspegi eta esperientzia desberdinak** errespetatzea.
4. Gure ekintzen eta ekarpenen **erantzukizuna** hartzea.
5. **Iradokizun eraikitzailea** dotoretasunez eman eta onartu.
6. Gertatzen denean **kaltea konpontzeko** konpromisoa hartzea.
7. **Gure komunitatearen ongizatea** sustatzen eta mantentzen duten beste modu batzuetan jokatzea.

## Jokabide mugatuak

Gure komunitatean honako jokabide hauek mugatzea onartzen dugu. Jokabide horien kasuak, mehatxuak eta sustapena Jokabide Kode honen urraketak dira.

1. **Jazarpena.** Espresuki adierazitako mugak urratzea edo alferrikako arreta pertsonala hartzea gelditzeko eskaera argi baten ondoren.
2. **Pertsonaien erasoak.** Komunitateko kide edo pertsona talde bati zuzendutako iruzkin iraingarriak, apalak edo iraingarriak egitea.
3. **Estereotipoa edo diskriminazioa.** Inoren nortasuna edo jokabidea aldaezin diren identitate edo ezaugarrien arabera ezaugarritzea.
4. **Sexualizazioa.** Komunitatearen testuinguruan edo helburuan orokorrean desegoki intimotzat hartuko litzatekeen moduan jokatzea.
5. **Konfidentzialtasuna urratzea**. Norbaiten informazio pertsonala edo pribatua partekatzea edo jardutea bere baimenik gabe.
6. **Arriskua.** Edozein pertsona edo talderi indarkeria edo bestelako kalteak eragitea, bultzatzea edo mehatxatzea.
7. Gure komunitatearen ongizatea **mehatxatzen** duten beste modu batzuetan jokatzea.

### Beste muga batzuk

1. **Identitatea engainagarria.** Edozein arrazoirengatik beste norbait ordezkatzea edo betearazte-ekintzak saihesteko beste norbait dela itxuratzea.
2. **Iturburuak ez kreditatu.** Ekartzen dituzun edukien iturriak behar bezala ez kreditatu.
3. **Promozio materialak**. Marketing edo bestelako eduki komertzialak komunitatearen arauetatik kanpo partekatzea.
4. **Arduragabeko komunikazioa.** Edukia arduraz ez aurkeztea, mugatutako beste jokabideren bat barne, lotzen edo deskribatzen duena.

## Arazo baten berri ematea

Tentsioak sor daitezke komunitateko kideen artean lankidetzan ari direnean ere. Gatazka guztiek ez dute jokabide-kode hausterik adierazten, eta Jokabide Kode honek gatazkak saihesten eta kalteak minimizatzen lagun ditzaketen jokabide eta arau bultzatuak indartzen ditu.

Gertaera bat gertatzen denean, garrantzitsua da berehala jakinaraztea. Balizko urraketa baten berri emateko, **[OHARRA: deskribatu hemen salatzeko dituzun baliabideak.]**

Komunitateko moderatzaileek serio hartzen dituzte urraketen txostenak eta ahalegin guztiak egingo dituzte garaiz erantzuteko. Jokabide-kodeen urraketen txosten guztiak ikertuko dituzte, mezuak, erregistroak eta grabazioak aztertuz edo lekukoak eta beste parte-hartzaile batzuk elkarrizketatuz. Komunitateko moderatzaileek ikerketa eta betearazteko ekintzak ahalik eta gardenen mantenduko dituzte, segurtasuna eta konfidentzialtasuna lehenesten dituzten bitartean. Balio horiek errespetatzeko, betearazpen-ekintzak pribatuan egiten dira inplikatutako alderdiekin, baina komunitate osoari komunikatzea elkarrekin adostutako ebazpen baten parte izan daiteke.

## Kalteak bideratzea eta konpontzea

**[OHARRA: Jarraian azaltzen diren konponketak eta konponketak jokabide-kodea betearazteko praktika onenetan oinarritutako iradokizunak dira. Zure komunitateak ezarritako betearazpen-prozesu propioa badu, ziurtatu atal hau editatzen duzula zure politikak deskribatzeko.]**

Komunitateko Moderatzaileek egindako ikerketa batek Jokabide Kode hau urratu dela ikusten badu, honako betearazpen-eskailera hau erabil daiteke kalteak konpontzeko modurik onena zehazteko, gertakariak inplikatutako pertsonengan eta komunitate osoan izan duen eragina kontuan hartuta. Arau-haustearen larritasunaren arabera, eskaileraren beheko eskailerak saltatu daitezke.

1) Abisua
 ) Gertaera: Gertakari bakar bat edo gertakari sorta bat dakarren arau-haustea.
 ) Ondorioa: Komunitate Moderatzaileen idatzizko ohartarazpena.
 ) Konponketa: konponketaren adibideen artean, idatzizko barkamen pribatua, erantzukizuna aitortzea eta itxaropenak argitzea.
2) Aldi baterako jarduera mugatuak
 ) Gertaera: aldez aurretik abisua eragin zuen arau-haustearen behin eta berriz gertatutakoa, edo arau-hauste larriago baten lehenengo intzidentzia.
 ) Ondorioa: idatzizko abisu pribatua, denbora mugatuko hozte-epearekin, egoeraren larritasuna azpimarratzeko eta inplikatutako komunitateko kideei gertakaria prozesatzeko denbora emateko. Hozte-epea komunikazio-kanal zehatzetara edo komunitateko kide jakin batzuekin elkarrekintzara mugatu daiteke.
 ) Konponketa: konponketa-adibideen artean barkamena eskatzea, hozte-aldia erabiltzea ekintzei eta eraginei buruz hausnartzeko eta aldia amaitu ondoren komunitateko espazioetara berriro sartzeko gogoeta egitea izan daiteke.
3) Aldi baterako etetea
 ) Gertaera: Komunitate Moderatzaileak ohartarazpenekin konpontzen saiatu diren behin eta berriz urratze-eredua edo urraketa larri bakarra.
 ) Ondorioa: Idatzizko ohartarazpen pribatua, etenalditik itzultzeko baldintzekin. Oro har, behin-behineko etenaldiek denbora ematen diote suspendituta dagoen pertsonari bere jokabideari eta ekintza zuzentzaile posibleei buruz hausnartzeko.
 ) Konponketa: konponketaren adibide dira etenaldiaren espiritua errespetatzea, itzultzeko zehaztutako baldintzak betetzea eta etenaldia kentzen denean komunitatean nola txertatu behar den hausnartzea.
4) Debeku iraunkorra
 ) Gertaera: eskailerako beste urrats batzuek ebatzi ez duten jokabide-kode errepikatuen eredua, edo hain larria den urraketa bat, non Komunitate Moderatzaileek erabakitzen duten ez dagoela komunitatea seguru mantentzeko modurik pertsona hau kide gisa.
 ) Ondorioa: komunitateko espazio, tresna eta komunikazio-bide guztietarako sarbidea kentzen da. Oro har, debeku iraunkorrak gutxitan erabili behar dira, arrazoi sendoak izan behar dituzte atzean, eta beste erremedio batzuekin lan egiteak jokabidea aldatzea lortu ez badu soilik jo behar da.
 ) Konponketa: larritasun honetako kasuetan ez dago konponketa posiblerik.

Betetzeko eskailera hau jarraibide gisa pentsatuta dago. Ez du mugatzen Community Manager-ek beren diskrezioa eta epaia erabiltzeko duten gaitasuna, gure komunitatearen interesen arabera.

## Eremua

Jokabide Kode hau komunitate-espazio guztietan aplikatzen da, eta pertsona bat komunitatea ofizialki ordezkatzen ari denean ere aplikatzen da espazio publikoetan edo bestelakoetan. Gure komunitatea ordezkatzeko adibide batzuk honako hauek dira: helbide elektroniko ofizial bat erabiltzea, sare sozialetako kontu ofizial baten bidez argitaratzea edo lineako edo lineaz kanpoko ekitaldi batean izendatutako ordezkari gisa jardutea.
