# 貢獻者契約 3.0 行為準則

## 我們的承諾

我們承諾讓我們的社區對所有人來說都是熱情、安全和公平的。

我們致力於營造一個尊重和促進所有人尊嚴、權利和貢獻的環境，無論其種族、民族、種姓、膚色、年齡、身體特徵、神經多樣性、殘疾、性別、性別認同或表達、性取向、語言、哲學或宗教、民族或社會出身、社會經濟地位、教育水平或其他狀況等特徵如何。所有真誠地並根據本公約參與的人都享有同樣的參與特權。

## 鼓勵行為

在承認社會規範差異的同時，我們都努力滿足社區對正向行為的期望。我們也了解，根據文化、背景或母語，我們的言語和行為可能會被解讀為與我們的意圖不同的方式。

考慮到這些因素，我們同意謹慎對待彼此，並以我們共同的價值觀為中心，包括：

1. 尊重**我們社區的目的**、我們的活動和我們的聚會方式。
2. **友善且誠實**地與他人交往。
3. 尊重**不同的觀點**和經驗。
4. **對我們的行為和貢獻承擔責任**。
5. 優雅地給予和接受**建設性回饋**。
6. 承諾在傷害發生時**修復傷害**。
7. 以其他方式行事以促進和維持**我們社區的福祉**。

## 限制行為

我們同意限制我們社區中的以下行為。此類行為的實例、威脅和宣揚均違反本行為準則。

1. **騷擾。 ** 違反明確表達的界限或在明確要求停止後進行不必要的個人關注。
2. **人格攻擊。 ** 針對社群成員或一群人發表侮辱、貶低或貶抑的評論。
3. **刻板印像或歧視。 ** 基於不可改變的身份或特徵來描述任何人的個性或行為。
4. **性化。 ** 行為方式在社區背景或目的中通常被認為是不適當的親密行為。
5. **違反保密規定**。未經他人許可，分享他人的個人或私人資訊或對其採取行動。
6. **危害。 ** 對任何個人或團體造成、鼓勵或威脅使用暴力或其他傷害。
7. 以其他方式**威脅我們社區的福祉**。

### 其他限制

1. **誤導性別認同。 ** 以任何理由冒充他人，或冒充他人以逃避執法行動。
2. **未能註明來源。 ** 未正確註明您所貢獻內容的來源。
3. **宣傳資料**。以超越社群規範的方式分享行銷或其他商業內容。
4. **不負責任的溝通。 ** 未能負責任地呈現包含、連結或描述任何其他受限行為的內容。

## 報告問題

即使社區成員盡力合作，他們之間也可能會出現緊張關係。並非每一次衝突都違反了行為準則，本行為準則強化了鼓勵的行為和規範，有助於避免衝突並最大程度地減少傷害。

當事件確實發生時，及時報告很重要。要舉報可能的違規行為，**[注意：在此處描述您的舉報方式。 ]**

社群版主嚴肅看待違規舉報，並將盡一切努力及時回應。他們將調查所有違反行為準則的報告，審查訊息、日誌和錄音，或採訪目擊者和其他參與者。社群版主將盡可能保持調查和執法行動透明，同時優先考慮安全和保密。為了尊重這些價值觀，執法行動是與相關各方私下進行的，但與整個社區的溝通可能是雙方商定的解決方案的一部分。

## 解決和修復危害

**[注意：以下概述的補救措施和修復是基於行為準則執行最佳實踐的建議。如果您的社區有自己既定的執行流程，請務必編輯此部分以描述您自己的政策。 ]**

如果社群版主的調查發現有人違反了本行為準則，則可以根據事件對相關個人和整個社群的影響，使用以下執法階梯來確定如何最好地修復傷害。根據違規的嚴重程度，可以跳過梯子上較低的梯級。

1) 警告
 ) 事件：涉及單一事件或一系列事件的違規行為。
 ) 結果：來自社區版主的私人書面警告。
 ) 修復：修復的範例包括私下書面道歉、承認責任以及尋求對期望的澄清。
2) 暫時限制活動
 ) 事件：先前導致警告的重複發生的違規行為，或首次發生更嚴重的違規行為。
 ) 後果：私人書面警告，並有一定時間限制的冷卻期，旨在強調情況的嚴重性，並為相關社區成員提供處理事件的時間。冷卻期可能僅限於特定的溝通管道或與特定社區成員的互動。
 ) 修復：修復的例子可能包括道歉、利用冷卻期反思行動和影響，以及在冷卻期結束後考慮重新進入社區空間。
3) 暫時停止
 ) 事件：社群版主試圖透過警告來解決的重複違規行為，或單次嚴重違規行為。
 ) 後果：私人書面警告，附有暫停返回的條件。一般來說，臨時停職讓被停職​​的人有時間反思自己的行為和可能的糾正措施。
 ）修復：修復的例子包括尊重停課精神、滿足規定的回歸條件、考慮停課解除後如何重新融入社區等。
4) 永久禁令
 ) 事件：一種重複違反行為準則且階梯上的其他步驟未能解決的模式，或者違規行為非常嚴重，以至於社區版主確定無法以該人作為成員來保證社區的安全。
 ) 結果：所有社區空間、工具和溝通管道的存取權限均被刪除。一般來說，永久禁令應該很少使用，應該有強有力的理由，並且只有在透過其他補救措施未能改變行為時才應採取。
 ) 修復：對於這種嚴重程度的情況，無法進行修復。

此執法階梯旨在作為指導方針。它並沒有限制社群管理者根據社群的最大利益運用自由裁量權和判斷力的能力。

## 範圍

本行為準則適用於所有社區空間，也適用於個人在公共或其他空間正式代表社區的情況。代表我們社群的範例包括使用官方電子郵件地址、透過官方社群媒體帳號發佈或在線上或線下活動中擔任指定代表。
