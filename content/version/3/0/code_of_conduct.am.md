# የአስተዋጽዖ አበርካች ቃል ኪዳን 3.0 የሥነ ምግባር ደንብ

## የኛ ቃል ኪዳን

ማህበረሰባችን እንግዳ ተቀባይ፣ ደህንነቱ የተጠበቀ እና ለሁሉም እኩል እንዲሆን ለማድረግ ቃል እንገባለን።

ዘር፣ ጎሣ፣ ዘር፣ ቀለም፣ ዕድሜ፣ የአካል ባህሪያት፣ የነርቭ ልዩነት፣ አካል ጉዳተኝነት፣ ጾታ ወይም ጾታ፣ የፆታ ማንነት ወይም አገላለጽ፣ ጾታዊ ዝንባሌ፣ ቋንቋ፣ ፍልስፍና ወይም ሃይማኖት፣ ብሄራዊ ወይም ማህበራዊ ምንጭ፣ ማህበራዊ-ኢኮኖሚያዊ ወይም ሌላ የትምህርት ደረጃን ጨምሮ የግለሰቦችን ክብር፣ መብት እና አስተዋጾ የሚያከብር እና የሚያበረታታ አካባቢን ለማዳበር ቆርጠን ተነስተናል። በቅን ልቦና እና በዚህ ቃል ኪዳን መሰረት ለሚሳተፉ ሰዎች ሁሉ ተመሳሳይ የመሳተፍ እድሎች ተሰጥተዋል።

## የሚበረታቱ ባህሪዎች

በማህበራዊ ደንቦች ውስጥ ያሉ ልዩነቶችን እያወቅን፣ ሁላችንም ማህበረሰባችን ለአዎንታዊ ባህሪ የሚጠብቀውን ለማሟላት እንተጋለን። እንዲሁም ቃላቶቻችን እና ተግባሮቻችን በባህል፣በጀርባ ወይም በአፍ መፍቻ ቋንቋ ላይ ተመስርተው ከምንፈልገው በተለየ መልኩ ሊተረጎሙ እንደሚችሉ እንረዳለን።

እነዚህን ከግምት ውስጥ በማስገባት፣ እርስ በርስ በማስተዋል ለመተሳሰብ እና የጋራ እሴቶቻችንን በሚያማክሩ መንገዶች ለመስራት ተስማምተናል፣ ጨምሮ፡-

1. የማህበረሰባችንን ** አላማ፣ እንቅስቃሴዎቻችን እና የመሰብሰቢያ መንገዶቻችንን ማክበር።
2. **በደግነት እና በቅንነት** ከሌሎች ጋር መሳተፍ።
3. ** የተለያዩ አመለካከቶችን እና ልምዶችን ማክበር።
4. ለድርጊታችን እና ለሚያበረክቱት አስተዋጾ ሀላፊነት መውሰድ።
5. በጸጋ መስጠት እና መቀበል ** ገንቢ አስተያየት ***።
6. በሚከሰትበት ጊዜ ** ጉዳትን ለመጠገን ቁርጠኝነት።
7. የማህበረሰባችንን **ደህንነት** የሚያበረታቱ እና የሚደግፉ ሌሎች መንገዶችን ማሳየት።

## የተከለከሉ ባህሪያት

በማኅበረሰባችን ውስጥ የሚከተሉትን ባህሪያት ለመገደብ ተስማምተናል። ምሳሌዎች፣ ዛቻዎች እና የእነዚህ ባህሪያት ማስተዋወቅ የዚህን የስነምግባር ህግ መጣስ ናቸው።

1. ** ትንኮሳ።** በግልጽ የተገለጹ ድንበሮችን መጣስ ወይም ለማቆም ግልጽ ጥያቄ ካለ በኋላ አላስፈላጊ የግል ትኩረት ውስጥ መግባት።
2. **የገጸ-ባህሪያት ጥቃት።** በአንድ የማህበረሰብ አባል ወይም ቡድን ላይ የሚሰነዘሩ ዘለፋ፣ ማንቋሸሽ ወይም ቀና አስተያየቶችን መስጠት።
3. **መተየብ ወይም መድልዎ።** የማንም ሰው ስብዕና ወይም ባህሪ በማይለወጡ ማንነቶች ወይም ባህሪያት ላይ በመመስረት።
4. **ወሲባዊነት።** በማህበረሰቡ አውድ ወይም አላማ ውስጥ በአጠቃላይ አግባብነት የጎደለው ነው ተብሎ የሚታሰብ ባህሪን ማሳየት።
5. **ሚስጥራዊነትን መጣስ**። ያለፈቃዳቸው የአንድን ሰው የግል ወይም የግል መረጃ ማጋራት ወይም መስራት።
6. **አደጋ።** በማንኛዉም ሰው ወይም ቡድን ላይ ሁከት መፍጠር፣ ማበረታታት ወይም ማስፈራራት ወይም ሌላ ጉዳት።
7. የማህበረሰባችንን ደህንነት አደጋ ላይ የሚጥሉ ሌሎች መንገዶችን ማሳየት።

### ሌሎች ገደቦች

1. ** አሳሳች ማንነት።** በማናቸውም ምክንያት ሌላን ሰው ማስመሰል ወይም ሌላ ሰው መስሎ የማስፈጸም እርምጃዎችን ለማምለጥ።
2. **የክሬዲት ምንጮችን አለመስጠት።** ያበረከቱትን የይዘት ምንጮች በትክክል አለመስጠት።
3. ** የማስተዋወቂያ ቁሶች ***. ከማህበረሰቡ ደንቦች ውጭ በሆነ መንገድ የግብይት ወይም ሌላ የንግድ ይዘት ማጋራት።
4. ** ኃላፊነት የጎደለው ግንኙነት።

## ጉዳይ ሪፖርት ማድረግ

በማህበረሰብ አባላት መካከል ለመተባበር የተቻላቸውን ያህል እየሞከሩም ቢሆን ውጥረት ሊፈጠር ይችላል። እያንዳንዱ ግጭት የስነምግባር ጥሰትን አይወክልም፣ እና ይህ የስነምግባር ህግ ግጭቶችን ለማስወገድ እና ጉዳትን ለመቀነስ የሚረዱ የተበረታቱ ባህሪዎችን እና ደንቦችን ያጠናክራል።

አንድ ክስተት ሲከሰት ወዲያውኑ ሪፖርት ማድረግ አስፈላጊ ነው. ሊደርስ የሚችል ጥሰትን ሪፖርት ለማድረግ **[ማስታወሻ፡ የሪፖርት ማድረጊያ ዘዴዎን እዚህ ይግለጹ።]**

የማህበረሰብ አወያዮች የጥሰቶችን ሪፖርቶች በቁም ነገር ይመለከቱታል እና ወቅታዊ ምላሽ ለመስጠት ሁሉንም ጥረት ያደርጋሉ። ሁሉንም የስነምግባር ጥሰት ሪፖርቶችን ይመረምራሉ፣ መልእክቶችን፣ ምዝግቦችን እና ቅጂዎችን በመገምገም ወይም ምስክሮችን እና ሌሎች ተሳታፊዎችን ቃለ መጠይቅ ያደርጋሉ። የማህበረሰብ አወያዮች ለደህንነት እና ምስጢራዊነት ቅድሚያ ሲሰጡ የምርመራ እና የማስፈጸሚያ እርምጃዎች በተቻለ መጠን ግልጽነት ይኖራቸዋል። እነዚህን እሴቶች ለማክበር የማስፈጸሚያ እርምጃዎች ከሚመለከታቸው አካላት ጋር በድብቅ ይከናወናሉ, ነገር ግን ከመላው ማህበረሰብ ጋር መግባባት የጋራ ስምምነት አካል ሊሆን ይችላል.

## ጉዳቱን ማስተናገድ እና መጠገን

**[ማስታወሻ፡ ከዚህ በታች የተዘረዘሩት መፍትሄዎች እና ጥገናዎች በሥነ-ምግባር ደንቡ ውስጥ ባሉ ምርጥ ተሞክሮዎች ላይ የተመሰረቱ አስተያየቶች ናቸው። የእርስዎ ማህበረሰብ የራሱ የሆነ የማስፈጸሚያ ሂደት ካለው፣ የእራስዎን ፖሊሲዎች ለመግለፅ ይህንን ክፍል ማርትዕዎን ያረጋግጡ።]**

በማህበረሰብ አወያዮች የተደረገው ምርመራ ይህ የስነምግባር ህግ እንደተጣሰ ካረጋገጠ፣ ክስተቱ በተሳተፉ ግለሰቦች እና በአጠቃላይ ማህበረሰቡ ላይ የሚኖረውን ተፅእኖ መሰረት በማድረግ ጉዳቱን እንዴት ማስተካከል እንደሚቻል ለመወሰን የሚከተለውን የማስፈጸሚያ መሰላል መጠቀም ይቻላል። እንደ ጥሰቱ ክብደት፣ በመሰላሉ ላይ ያሉ ዝቅተኛ ደረጃዎች ሊዘለሉ ይችላሉ።

1) ማስጠንቀቂያ
 ) ክስተት፡ አንድ ነጠላ ክስተት ወይም ተከታታይ ክስተቶችን የሚያካትት ጥሰት።
 ) መዘዝ፡ ከማህበረሰብ አወያዮች የግል፣ የጽሁፍ ማስጠንቀቂያ።
 ) መጠገን፡ የጥገና ምሳሌዎች የግል የጽሁፍ ይቅርታ መጠየቅን፣ ሃላፊነትን መቀበል እና ስለሚጠበቁ ነገሮች ማብራሪያ መፈለግን ያካትታሉ።
2) ለጊዜው የተገደቡ ተግባራት
 ) ክስተት፡ ከዚህ ቀደም ማስጠንቀቂያ ያስከተለ የጥሰት ተደጋጋሚ ክስተት፣ ወይም የመጀመሪያው የከፋ ጥሰት ክስተት።
 መዘዝ፡ የሁኔታውን አሳሳቢነት ለማጉላት እና የተሳተፉት የማህበረሰቡ አባላት ክስተቱን ለማስኬድ ጊዜ ለመስጠት የተነደፈ ጊዜ-ውሱን የማቀዝቀዝ ጊዜ ያለው የግል፣ የጽሁፍ ማስጠንቀቂያ። የመቀዝቀዣው ጊዜ ለተወሰኑ የመገናኛ መስመሮች ወይም ከተወሰኑ የማህበረሰብ አባላት ጋር ባለው ግንኙነት ሊገደብ ይችላል።
 ) መጠገን፡ የጥገና ምሳሌዎች ይቅርታ መጠየቅን፣ የማቀዝቀዝ ጊዜን በመጠቀም ድርጊቶችን እና ተፅዕኖዎችን ለማንፀባረቅ እና ጊዜው ካለፈ በኋላ እንደገና ወደ ማህበረሰብ ቦታዎች ለመግባት ማሰብን ሊያካትት ይችላል።
3) ጊዜያዊ እገዳ
 ) ክስተት፡ የማህበረሰብ አወያዮች በማስጠንቀቂያዎች ለመፍታት የሞከሩት ተደጋጋሚ ጥሰት ዘይቤ፣ ወይም አንድ ከባድ ጥሰት።
 ) መዘዝ፡- ከዕገዳ ለመመለስ ሁኔታዎችን የያዘ የግል የጽሁፍ ማስጠንቀቂያ። በአጠቃላይ፣ ጊዜያዊ እገዳዎች የታገደው ሰው ባህሪያቸውን እና የእርምት እርምጃዎችን እንዲያሰላስል ጊዜ ይሰጡታል።
 ) ጥገና፡ የጥገና ምሳሌዎች የእገዳውን መንፈስ ማክበር፣ የተገለጹትን የመመለሻ ሁኔታዎች ማሟላት እና እገዳው በሚነሳበት ጊዜ ከማህበረሰቡ ጋር እንዴት እንደሚዋሃዱ ማሰብን ያካትታሉ።
4) ቋሚ እገዳ
 ) ክስተት፡ በመሰላሉ ላይ ያሉ ሌሎች እርምጃዎች ሊፈቱ ያልቻሉት ተደጋጋሚ የስነ ምግባር ደንብ ጥሰት፣ ወይም ጥሰት ከባድ ከመሆኑ የተነሳ የማህበረሰቡ አወያዮች ከዚህ ሰው ጋር እንደ አባልነት የማህበረሰቡን ደህንነት ለመጠበቅ ምንም አይነት መንገድ እንደሌለ ወስነዋል።
 መዘዝ፡ የሁሉም የማህበረሰብ ቦታዎች፣ መሳሪያዎች እና የመገናኛ መንገዶች መዳረሻ ተወግዷል። በአጠቃላይ, ቋሚ እገዳዎች እምብዛም ጥቅም ላይ መዋል አለባቸው, ከኋላቸው ጠንካራ ምክንያት ሊኖራቸው ይገባል, እና በሌሎች መፍትሄዎች መስራት ባህሪውን መቀየር ካልቻለ ብቻ ነው.
 ) ጥገና፡ በዚህ ከባድነት ሊጠገን የሚችል ነገር የለም።

ይህ የማስፈጸሚያ መሰላል እንደ መመሪያ የታሰበ ነው። የማህበረሰቡ አስተዳዳሪዎች የማህበረሰባችንን ጥቅም አስጠብቀው የራሳቸውን ውሳኔ እና ውሳኔ የመጠቀም አቅማቸውን አይገድበውም።

## ወሰን

ይህ የስነምግባር ህግ በሁሉም የማህበረሰብ ክፍሎች ውስጥ የሚተገበር ሲሆን እንዲሁም አንድ ግለሰብ ማህበረሰቡን በይፋ ወይም በሌሎች ቦታዎች ሲወክልም ተፈጻሚ ይሆናል። ማህበረሰባችንን የመወከል ምሳሌዎች ኦፊሴላዊ ኢሜል አድራሻን መጠቀም፣ በኦፊሴላዊ የማህበራዊ ሚዲያ መለያ መለጠፍ ወይም በመስመር ላይ ወይም ከመስመር ውጭ ክስተት ላይ እንደ ተሾመ ተወካይ መሆንን ያካትታሉ።
