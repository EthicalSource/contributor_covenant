# ફાળો આપનાર કરાર 3.0 આચાર સંહિતા

## અમારી પ્રતિજ્ઞા

અમે અમારા સમુદાયને બધા માટે આવકારદાયક, સલામત અને સમાન બનાવવાનો સંકલ્પ કરીએ છીએ.

અમે એવા વાતાવરણને ઉત્તેજન આપવા માટે પ્રતિબદ્ધ છીએ જે જાતિ, વંશીયતા, જાતિ, રંગ, ઉંમર, શારીરિક લાક્ષણિકતાઓ, ચેતાવિવિધતા, વિકલાંગતા, લિંગ અથવા લિંગ, લિંગ ઓળખ અથવા અભિવ્યક્તિ, લૈંગિક અભિમુખતા, ભાષા, ફિલસૂફી અથવા સામાજિક સ્થિતિ, સામાજિક સ્થિતિ, સામાજિક અથવા સામાજિક સ્તર સહિતની લાક્ષણિકતાઓને ધ્યાનમાં લીધા વિના તમામ વ્યક્તિઓના ગૌરવ, અધિકારો અને યોગદાનને આદર આપે છે અને પ્રોત્સાહન આપે છે. શિક્ષણ, અથવા અન્ય સ્થિતિ. સહભાગિતાના સમાન વિશેષાધિકારો સદ્ભાવનાથી અને આ કરાર અનુસાર ભાગ લેનારા દરેકને આપવામાં આવે છે.

## પ્રોત્સાહિત વર્તન

સામાજિક ધોરણોમાં તફાવતોને સ્વીકારતી વખતે, અમે બધા સકારાત્મક વર્તન માટે અમારા સમુદાયની અપેક્ષાઓને પૂર્ણ કરવાનો પ્રયત્ન કરીએ છીએ. અમે એ પણ સમજીએ છીએ કે સંસ્કૃતિ, પૃષ્ઠભૂમિ અથવા મૂળ ભાષાના આધારે અમારા શબ્દો અને કાર્યોનું અર્થઘટન અલગ રીતે થઈ શકે છે.

આ વિચારણાઓને ધ્યાનમાં રાખીને, અમે એકબીજા પ્રત્યે મનથી વર્તવા અને અમારા શેર કરેલા મૂલ્યોને કેન્દ્રમાં રાખીને કાર્ય કરવા સંમત છીએ, જેમાં નીચેનાનો સમાવેશ થાય છે:

1. **અમારા સમુદાયના હેતુ**, અમારી પ્રવૃત્તિઓ અને એકત્ર થવાની અમારી રીતોને માન આપવું.
2. અન્ય લોકો સાથે **દયાળુ અને પ્રમાણિકતાથી** સંલગ્ન રહો.
3. **વિવિધ દૃષ્ટિકોણ** અને અનુભવોનો આદર કરવો.
4. અમારી ક્રિયાઓ અને યોગદાન માટે **જવાબદારી લેવી**.
5. **રચનાત્મક પ્રતિસાદ** આપવી અને સ્વીકારવી.
6. જ્યારે તે થાય ત્યારે **સુરામત કરવા માટે પ્રતિબદ્ધતા.
7. અન્ય રીતે વર્તવું કે જે **આપણા સમુદાયની સુખાકારી**ને પ્રોત્સાહન આપે અને ટકાવી રાખે.

## પ્રતિબંધિત વર્તન

અમે અમારા સમુદાયમાં નીચેના વર્તનને પ્રતિબંધિત કરવા માટે સંમત છીએ. આ વર્તણૂકોના દાખલા, ધમકીઓ અને પ્રોત્સાહન આ આચાર સંહિતાનું ઉલ્લંઘન છે.

1. **સતામણ.** સ્પષ્ટપણે વ્યક્ત કરેલી સીમાઓનું ઉલ્લંઘન કરવું અથવા રોકવાની કોઈપણ સ્પષ્ટ વિનંતી પછી બિનજરૂરી વ્યક્તિગત ધ્યાન આપવું.
2. **પાત્ર હુમલા.** સમુદાયના સભ્ય અથવા લોકોના જૂથ પર નિર્દેશિત અપમાનજનક, અપમાનજનક અથવા અપમાનજનક ટિપ્પણીઓ કરવી.
3. **સ્ટીરિયોટાઇપિંગ અથવા ભેદભાવ.** અપરિવર્તનશીલ ઓળખ અથવા લક્ષણોના આધારે કોઈપણ વ્યક્તિના વ્યક્તિત્વ અથવા વર્તનની લાક્ષણિકતા.
4. **જાતીયકરણ.** એવી રીતે વર્તવું કે જે સામાન્ય રીતે સમુદાયના સંદર્ભ અથવા હેતુમાં અયોગ્ય રીતે ઘનિષ્ઠ માનવામાં આવે.
5. **ગોપનીયતાનું ઉલ્લંઘન કરવું**. કોઈની અંગત અથવા ખાનગી માહિતી તેમની પરવાનગી વિના શેર કરવી અથવા તેના પર કાર્ય કરવું.
6. **સંકટ.** કોઈપણ વ્યક્તિ અથવા જૂથ પ્રત્યે હિંસા અથવા અન્ય નુકસાન પહોંચાડવું, પ્રોત્સાહિત કરવું અથવા ધમકી આપવી.
7. અન્ય રીતે વર્તવું કે જે **આપણા સમુદાયની સુખાકારીને જોખમમાં મૂકે**.

### અન્ય પ્રતિબંધો

1. **ભ્રામક ઓળખ.** કોઈપણ કારણસર અન્ય કોઈની નકલ કરવી, અથવા અમલીકરણની ક્રિયાઓ ટાળવા માટે કોઈ અન્ય હોવાનો ડોળ કરવો.
2. **ધિરાણ સ્ત્રોતોમાં નિષ્ફળતા.** તમે યોગદાન આપો છો તે સામગ્રીના સ્ત્રોતોને યોગ્ય રીતે ક્રેડિટ નથી.
3. **પ્રમોશનલ સામગ્રી**. માર્કેટિંગ અથવા અન્ય વ્યાપારી સામગ્રી એવી રીતે શેર કરવી કે જે સમુદાયના ધોરણોની બહાર હોય.
4. **બેજવાબદાર સંદેશાવ્યવહાર.** જવાબદારીપૂર્વક એવી સામગ્રી રજૂ કરવામાં નિષ્ફળતા કે જેમાં કોઈપણ અન્ય પ્રતિબંધિત વર્તણૂકોનો સમાવેશ, લિંક અથવા વર્ણન હોય.

## સમસ્યાની જાણ કરવી

સમુદાયના સભ્યો જ્યારે સહયોગ કરવાનો શ્રેષ્ઠ પ્રયાસ કરી રહ્યા હોય ત્યારે પણ તેઓ વચ્ચે તણાવ પેદા થઈ શકે છે. દરેક સંઘર્ષ આચારસંહિતાના ઉલ્લંઘનનું પ્રતિનિધિત્વ કરતું નથી, અને આ આચાર સંહિતા પ્રોત્સાહિત વર્તણૂકો અને ધોરણોને વધુ મજબૂત બનાવે છે જે સંઘર્ષને ટાળવામાં અને નુકસાનને ઘટાડવામાં મદદ કરી શકે છે.

જ્યારે કોઈ ઘટના બને છે, ત્યારે તેની તાત્કાલિક જાણ કરવી મહત્વપૂર્ણ છે. સંભવિત ઉલ્લંઘનની જાણ કરવા માટે, **[નોંધ: અહીં જાણ કરવાના તમારા માધ્યમનું વર્ણન કરો.]**

સમુદાયના મધ્યસ્થીઓ ઉલ્લંઘનોના અહેવાલોને ગંભીરતાથી લે છે અને સમયસર જવાબ આપવા માટે દરેક પ્રયાસ કરશે. તેઓ આચારસંહિતાના ઉલ્લંઘનના તમામ અહેવાલોની તપાસ કરશે, સંદેશાઓ, લોગ્સ અને રેકોર્ડિંગ્સની સમીક્ષા કરશે અથવા સાક્ષીઓ અને અન્ય સહભાગીઓની મુલાકાત લેશે. સમુદાયના મધ્યસ્થીઓ સલામતી અને ગોપનીયતાને પ્રાથમિકતા આપતી વખતે તપાસ અને અમલીકરણની ક્રિયાઓને શક્ય તેટલી પારદર્શક રાખશે. આ મૂલ્યોનું સન્માન કરવા માટે, અમલીકરણની ક્રિયાઓ સામેલ પક્ષો સાથે ખાનગીમાં હાથ ધરવામાં આવે છે, પરંતુ સમગ્ર સમુદાય સાથે વાતચીત કરવી એ પરસ્પર સંમત ઠરાવનો ભાગ હોઈ શકે છે.

## નુકસાનને સંબોધન અને સમારકામ

**[નોંધ: નીચે દર્શાવેલ ઉપાયો અને સમારકામ આચાર સંહિતા અમલીકરણની શ્રેષ્ઠ પદ્ધતિઓ પર આધારિત સૂચનો છે. જો તમારા સમુદાયની પોતાની સ્થાપિત અમલીકરણ પ્રક્રિયા છે, તો તમારી પોતાની નીતિઓનું વર્ણન કરવા માટે આ વિભાગને સંપાદિત કરવાની ખાતરી કરો.]**

જો સામુદાયિક મધ્યસ્થીઓની તપાસમાં જાણવા મળે છે કે આ આચાર સંહિતાનું ઉલ્લંઘન કરવામાં આવ્યું છે, તો નીચેના અમલીકરણ નિસરણીનો ઉપયોગ સામેલ વ્યક્તિઓ અને સમગ્ર સમુદાય પર ઘટનાની અસરના આધારે નુકસાનને કેવી રીતે શ્રેષ્ઠ રીતે સુધારવું તે નિર્ધારિત કરવા માટે થઈ શકે છે. ઉલ્લંઘનની ગંભીરતાના આધારે, નિસરણી પરના નીચલા ભાગોને છોડી શકાય છે.

1) ચેતવણી
 ) ઇવેન્ટ: એક જ ઘટના અથવા શ્રેણીબદ્ધ ઘટનાઓનું ઉલ્લંઘન.
 ) પરિણામ: સમુદાય મધ્યસ્થીઓ તરફથી ખાનગી, લેખિત ચેતવણી.
 ) સમારકામ: સમારકામના ઉદાહરણોમાં ખાનગી લેખિત માફી, જવાબદારીની સ્વીકૃતિ અને અપેક્ષાઓ પર સ્પષ્ટતા મેળવવાનો સમાવેશ થાય છે.
2) અસ્થાયી રૂપે મર્યાદિત પ્રવૃત્તિઓ
 ) ઇવેન્ટ: ઉલ્લંઘનની પુનરાવર્તિત ઘટના કે જે અગાઉ ચેતવણીમાં પરિણમી હતી અથવા વધુ ગંભીર ઉલ્લંઘનની પ્રથમ ઘટના.
 ) પરિણામ: પરિસ્થિતિની ગંભીરતાને રેખાંકિત કરવા અને ઘટનાની પ્રક્રિયા કરવા માટે સામેલ સમુદાયના સભ્યોને સમય આપવા માટે રચાયેલ સમય-મર્યાદિત કૂલડાઉન સમયગાળા સાથેની ખાનગી, લેખિત ચેતવણી. કૂલડાઉન સમયગાળો ચોક્કસ સંચાર ચેનલો અથવા ચોક્કસ સમુદાયના સભ્યો સાથેની ક્રિયાપ્રતિક્રિયાઓ સુધી મર્યાદિત હોઈ શકે છે.
 ) સમારકામ: સમારકામના ઉદાહરણોમાં માફી માંગવી, ક્રિયાઓ અને અસર પર પ્રતિબિંબિત કરવા માટે કૂલડાઉન અવધિનો ઉપયોગ કરવો અને સમયગાળો પૂરો થયા પછી સમુદાયની જગ્યાઓ પર ફરીથી પ્રવેશ કરવા વિશે વિચારશીલ રહેવું શામેલ હોઈ શકે છે.
3) કામચલાઉ સસ્પેન્શન
 ) ઇવેન્ટ: પુનરાવર્તિત ઉલ્લંઘનની એક પેટર્ન કે જેને સમુદાય મધ્યસ્થીઓએ ચેતવણીઓ અથવા એક ગંભીર ઉલ્લંઘન સાથે સંબોધવાનો પ્રયાસ કર્યો છે.
 ) પરિણામ: સસ્પેન્શનમાંથી પરત આવવા માટેની શરતો સાથેની ખાનગી લેખિત ચેતવણી. સામાન્ય રીતે, કામચલાઉ સસ્પેન્શન સસ્પેન્ડ કરવામાં આવેલ વ્યક્તિને તેના વર્તન અને સંભવિત સુધારાત્મક ક્રિયાઓ પર વિચાર કરવા માટે સમય આપે છે.
 ) સમારકામ: સમારકામના ઉદાહરણોમાં સસ્પેન્શનની ભાવનાનો આદર કરવો, વળતર માટે નિર્દિષ્ટ શરતો પૂરી કરવી અને સસ્પેન્શન હટાવવામાં આવે ત્યારે સમુદાય સાથે કેવી રીતે પુનઃ એકીકરણ કરવું તે અંગે વિચારશીલ હોવાનો સમાવેશ થાય છે.
4) કાયમી પ્રતિબંધ
 ) ઇવેન્ટ: આચારસંહિતાના પુનરાવર્તિત ઉલ્લંઘનની એક પેટર્ન કે જે નિસરણી પરના અન્ય પગલાંઓ ઉકેલવામાં નિષ્ફળ ગયા છે, અથવા ઉલ્લંઘન એટલું ગંભીર છે કે સમુદાય મધ્યસ્થીઓ નિર્ધારિત કરે છે કે સભ્ય તરીકે આ વ્યક્તિ સાથે સમુદાયને સુરક્ષિત રાખવાનો કોઈ રસ્તો નથી.
 ) પરિણામ: તમામ સમુદાય જગ્યાઓ, સાધનો અને સંચાર ચેનલોની ઍક્સેસ દૂર કરવામાં આવી છે. સામાન્ય રીતે, કાયમી પ્રતિબંધનો ભાગ્યે જ ઉપયોગ થવો જોઈએ, તેની પાછળ મજબૂત તર્ક હોવો જોઈએ, અને માત્ર ત્યારે જ આશરો લેવો જોઈએ જો અન્ય ઉપાયો દ્વારા કામ કરવાથી વર્તન બદલવામાં નિષ્ફળ ગયા હોય.
 ) સમારકામ: આ ગંભીરતાના કિસ્સામાં કોઈ શક્ય સમારકામ નથી.

આ અમલીકરણ નિસરણી માર્ગદર્શિકા તરીકે બનાવાયેલ છે. તે આપણા સમુદાયના શ્રેષ્ઠ હિતોને ધ્યાનમાં રાખીને, તેમના વિવેક અને નિર્ણયનો ઉપયોગ કરવાની સમુદાય સંચાલકોની ક્ષમતાને મર્યાદિત કરતું નથી.

## અવકાશ

આ આચાર સંહિતા તમામ સામુદાયિક જગ્યાઓમાં લાગુ થાય છે, અને જ્યારે કોઈ વ્યક્તિ સાર્વજનિક અથવા અન્ય જગ્યાઓમાં સમુદાયનું સત્તાવાર રીતે પ્રતિનિધિત્વ કરતી હોય ત્યારે પણ લાગુ પડે છે. અમારા સમુદાયનું પ્રતિનિધિત્વ કરવાના ઉદાહરણોમાં અધિકૃત ઈમેલ એડ્રેસનો ઉપયોગ કરવો, અધિકૃત સોશિયલ મીડિયા એકાઉન્ટ દ્વારા પોસ્ટ કરવું અથવા ઓનલાઈન અથવા ઑફલાઈન ઈવેન્ટમાં નિયુક્ત પ્રતિનિધિ તરીકે કામ કરવું શામેલ છે.
