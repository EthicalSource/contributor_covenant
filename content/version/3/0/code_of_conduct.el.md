# Κώδικας Δεοντολογίας Contributor Covenant 3.0

## Η υπόσχεσή μας

Δεσμευόμαστε να κάνουμε την κοινότητά μας φιλόξενη, ασφαλή και δίκαιη για όλους.

Δεσμευόμαστε να καλλιεργήσουμε ένα περιβάλλον που σέβεται και προάγει την αξιοπρέπεια, τα δικαιώματα και τις συνεισφορές όλων των ατόμων, ανεξαρτήτως χαρακτηριστικών όπως φυλή, εθνικότητα, κάστα, χρώμα, ηλικία, σωματικά χαρακτηριστικά, νευροποικιλομορφία, αναπηρία, φύλο ή φύλο, ταυτότητα ή έκφραση φύλου, σεξουαλικό προσανατολισμό, γλώσσα, φιλοσοφία ή θρησκεία, εθνική ή κοινωνική προέλευση, κοινωνική θέση, κοινωνική θέση. Τα ίδια προνόμια συμμετοχής επεκτείνονται σε όλους όσους συμμετέχουν καλόπιστα και σύμφωνα με το παρόν Σύμφωνο.

## Ενθαρρυντικές Συμπεριφορές

Αν και αναγνωρίζουμε τις διαφορές στα κοινωνικά πρότυπα, όλοι προσπαθούμε να ανταποκριθούμε στις προσδοκίες της κοινότητάς μας για θετική συμπεριφορά. Κατανοούμε επίσης ότι τα λόγια και οι πράξεις μας μπορεί να ερμηνεύονται διαφορετικά από ό,τι σκοπεύουμε με βάση τον πολιτισμό, το υπόβαθρο ή τη μητρική γλώσσα.

Έχοντας αυτές τις σκέψεις κατά νου, συμφωνούμε να συμπεριφερόμαστε προσεκτικά ο ένας προς τον άλλον και να ενεργούμε με τρόπους που επικεντρώνουν τις κοινές μας αξίες, όπως:

1. Σεβόμενοι τον **σκοπό της κοινότητάς μας**, τις δραστηριότητές μας και τους τρόπους συγκέντρωσης.
2. Αλληλεπίδραση **ευγενικά και ειλικρινά** με τους άλλους.
3. Σεβασμός **διαφορετικών απόψεων** και εμπειριών.
4. **Αναλαμβάνοντας την ευθύνη** για τις ενέργειες και τις συνεισφορές μας.
5. Δίνοντας και αποδεχόμενοι με χάρη **εποικοδομητική ανατροφοδότηση**.
6. Δέσμευση για **αποκατάσταση βλάβης** όταν συμβεί.
7. Συμπεριφορά με άλλους τρόπους που προάγουν και συντηρούν την **ευημερία της κοινότητάς μας**.

## Περιορισμένες Συμπεριφορές

Συμφωνούμε να περιορίσουμε τις ακόλουθες συμπεριφορές στην κοινότητά μας. Οι περιπτώσεις, οι απειλές και η προώθηση αυτών των συμπεριφορών αποτελούν παραβιάσεις αυτού του Κώδικα Δεοντολογίας.

1. **Παρενόχληση.** Παραβίαση ρητά εκφραζόμενων ορίων ή εμπλοκή σε περιττή προσωπική προσοχή μετά από οποιοδήποτε σαφές αίτημα διακοπής.
2. **Επιθέσεις χαρακτήρων.** Προσβλητικά, υποτιμητικά ή υποτιμητικά σχόλια που απευθύνονται σε ένα μέλος της κοινότητας ή σε ομάδα ανθρώπων.
3. **Στερεότυπα ή διακρίσεις.** Χαρακτηρισμός της προσωπικότητας ή της συμπεριφοράς οποιουδήποτε με βάση αμετάβλητες ταυτότητες ή χαρακτηριστικά.
4. **Σεξουαλοποίηση.** Συμπεριφορά με τρόπο που γενικά θα μπορούσε να θεωρηθεί ακατάλληλα οικεία στο πλαίσιο ή τον σκοπό της κοινότητας.
5. **Παραβίαση του απορρήτου**. Κοινή χρήση ή ενεργοποίηση προσωπικών ή προσωπικών πληροφοριών κάποιου χωρίς την άδειά του.
6. **Κινδύνευση.** Πρόκληση, ενθάρρυνση ή απειλή βίας ή άλλης βλάβης σε οποιοδήποτε άτομο ή ομάδα.
7. Συμπεριφορά με άλλους τρόπους που **απειλούν την ευημερία** της κοινότητάς μας.

### Άλλοι Περιορισμοί

1. **Παραπλανητική ταυτότητα.** Μίμηση ταυτότητας κάποιου άλλου για οποιονδήποτε λόγο ή προσποίηση ότι είναι κάποιος άλλος για να αποφύγει ενέργειες επιβολής.
2. **Αποτυχία πίστωσης πηγών.** Μη σωστή πίστωση των πηγών περιεχομένου που συνεισφέρετε.
3. **Διαφημιστικό υλικό**. Κοινή χρήση μάρκετινγκ ή άλλου εμπορικού περιεχομένου με τρόπο που είναι εκτός των κανόνων της κοινότητας.
4. **Ανεύθυνη επικοινωνία.** Παράλειψη υπεύθυνης παρουσίασης περιεχομένου που περιλαμβάνει, συνδέει ή περιγράφει οποιαδήποτε άλλη περιορισμένη συμπεριφορά.

## Αναφορά προβλήματος

Μπορεί να προκύψουν εντάσεις μεταξύ των μελών της κοινότητας ακόμα και όταν προσπαθούν να συνεργαστούν. Δεν αποτελεί κάθε σύγκρουση παραβίαση κώδικα συμπεριφοράς και αυτός ο Κώδικας Δεοντολογίας ενισχύει ενθαρρυντικές συμπεριφορές και κανόνες που μπορούν να βοηθήσουν στην αποφυγή συγκρούσεων και στην ελαχιστοποίηση της ζημιάς.

Όταν συμβαίνει ένα περιστατικό, είναι σημαντικό να το αναφέρετε αμέσως. Για να αναφέρετε μια πιθανή παράβαση, **[ΣΗΜΕΙΩΣΗ: περιγράψτε τον τρόπο αναφοράς σας εδώ.]**

Οι συντονιστές της κοινότητας λαμβάνουν σοβαρά υπόψη τις αναφορές παραβιάσεων και θα καταβάλουν κάθε δυνατή προσπάθεια για να ανταποκριθούν έγκαιρα. Θα διερευνήσουν όλες τις αναφορές για παραβιάσεις του κώδικα δεοντολογίας, θα εξετάσουν μηνύματα, τα αρχεία καταγραφής και τις ηχογραφήσεις ή θα ανακρίνουν μάρτυρες και άλλους συμμετέχοντες. Οι συντονιστές της κοινότητας θα διατηρήσουν τις ενέργειες έρευνας και επιβολής όσο το δυνατόν πιο διαφανείς, δίνοντας παράλληλα προτεραιότητα στην ασφάλεια και την εμπιστευτικότητα. Προκειμένου να τηρηθούν αυτές οι αξίες, οι ενέργειες επιβολής πραγματοποιούνται κατ' ιδίαν με τα εμπλεκόμενα μέρη, αλλά η επικοινωνία σε ολόκληρη την κοινότητα μπορεί να αποτελεί μέρος μιας αμοιβαία συμφωνημένης επίλυσης.

## Αντιμετώπιση και αποκατάσταση βλάβης

**[ΣΗΜΕΙΩΣΗ: Τα διορθωτικά μέτρα και οι επισκευές που περιγράφονται παρακάτω είναι προτάσεις που βασίζονται στις βέλτιστες πρακτικές στην επιβολή του κώδικα δεοντολογίας. Εάν η κοινότητά σας έχει τη δική της καθιερωμένη διαδικασία επιβολής, φροντίστε να επεξεργαστείτε αυτήν την ενότητα για να περιγράψετε τις δικές σας πολιτικές.]**

Εάν μια έρευνα από τους συντονιστές της Κοινότητας διαπιστώσει ότι αυτός ο Κώδικας Συμπεριφοράς έχει παραβιαστεί, η ακόλουθη κλίμακα επιβολής μπορεί να χρησιμοποιηθεί για να προσδιοριστεί ο καλύτερος τρόπος αποκατάστασης της ζημιάς, με βάση τον αντίκτυπο του συμβάντος στα εμπλεκόμενα άτομα και στην κοινότητα στο σύνολό της. Ανάλογα με τη σοβαρότητα μιας παραβίασης, τα χαμηλότερα σκαλοπάτια στη σκάλα μπορεί να παραλειφθούν.

1) Προειδοποίηση
 ) Συμβάν: Παραβίαση που περιλαμβάνει ένα μεμονωμένο περιστατικό ή σειρά περιστατικών.
 ) Συνέπεια: Μια ιδιωτική, γραπτή προειδοποίηση από τους συντονιστές της Κοινότητας.
 ) Επισκευή: Τα παραδείγματα επισκευής περιλαμβάνουν μια ιδιωτική γραπτή συγγνώμη, αναγνώριση ευθύνης και αναζήτηση διευκρινίσεων σχετικά με τις προσδοκίες.
2) Προσωρινά Περιορισμένες Δραστηριότητες
 ) Συμβάν: Επαναλαμβανόμενο περιστατικό παραβίασης που προηγουμένως είχε ως αποτέλεσμα μια προειδοποίηση ή το πρώτο περιστατικό πιο σοβαρής παραβίασης.
 ) Συνέπεια: Μια ιδιωτική, γραπτή προειδοποίηση με μια χρονικά περιορισμένη περίοδο ανάπαυσης που έχει σχεδιαστεί για να υπογραμμίσει τη σοβαρότητα της κατάστασης και να δώσει χρόνο στα μέλη της κοινότητας που εμπλέκονται να διεκπεραιώσουν το περιστατικό. Η περίοδος χαλάρωσης μπορεί να περιορίζεται σε συγκεκριμένα κανάλια επικοινωνίας ή αλληλεπιδράσεις με συγκεκριμένα μέλη της κοινότητας.
 ) Επισκευή: Παραδείγματα επισκευής μπορεί να περιλαμβάνουν ζητώντας συγγνώμη, χρήση της περιόδου χαλάρωσης για προβληματισμό σχετικά με τις ενέργειες και τον αντίκτυπο και τη σκέψη σχετικά με την εκ νέου είσοδο στους χώρους της κοινότητας μετά το πέρας της περιόδου.
3) Προσωρινή Αναστολή
 ) Εκδήλωση: Ένα μοτίβο επαναλαμβανόμενης παραβίασης που οι συντονιστές της Κοινότητας προσπάθησαν να αντιμετωπίσουν με προειδοποιήσεις ή μια μεμονωμένη σοβαρή παραβίαση.
 ) Συνέπεια: Ιδιωτική γραπτή προειδοποίηση με προϋποθέσεις επιστροφής από αναστολή. Γενικά, οι προσωρινές αναστολές δίνουν στο άτομο που βρίσκεται σε αναστολή χρόνο να σκεφτεί τη συμπεριφορά του και τις πιθανές διορθωτικές ενέργειες.
 ) Επισκευή: Παραδείγματα επισκευής περιλαμβάνουν το σεβασμό του πνεύματος της αναστολής, την εκπλήρωση των καθορισμένων προϋποθέσεων επιστροφής και τη σκέψη σχετικά με τον τρόπο επανένταξης στην κοινότητα όταν αρθεί η αναστολή.
4) Μόνιμη Απαγόρευση
 ) Συμβάν: Ένα μοτίβο επαναλαμβανόμενων παραβιάσεων του κώδικα συμπεριφοράς που άλλα βήματα στη σκάλα απέτυχαν να επιλύσουν ή μια παράβαση τόσο σοβαρή που οι συντονιστές της κοινότητας προσδιορίζουν ότι δεν υπάρχει τρόπος να διατηρηθεί η κοινότητα ασφαλής με αυτό το άτομο ως μέλος.
 ) Συνέπεια: Καταργείται η πρόσβαση σε όλους τους χώρους της κοινότητας, τα εργαλεία και τα κανάλια επικοινωνίας. Γενικά, οι μόνιμες απαγορεύσεις θα πρέπει να χρησιμοποιούνται σπάνια, θα πρέπει να έχουν ισχυρό σκεπτικό πίσω τους και θα πρέπει να καταφεύγουν μόνο σε περίπτωση που η επεξεργασία άλλων διορθωτικών μέτρων έχει αποτύχει να αλλάξει τη συμπεριφορά.
 ) Επισκευή: Δεν υπάρχει πιθανή επισκευή σε περιπτώσεις αυτής της σοβαρότητας.

Αυτή η κλίμακα επιβολής προορίζεται ως κατευθυντήρια γραμμή. Δεν περιορίζει την ικανότητα των Διαχειριστών Κοινότητας να χρησιμοποιούν τη διακριτικότητα και την κρίση τους, σύμφωνα με τα βέλτιστα συμφέροντα της κοινότητάς μας.

Αυτός ο Κώδικας Συμπεριφοράς εφαρμόζεται σε όλους τους κοινοτικούς χώρους και επίσης ισχύει όταν ένα άτομο εκπροσωπεί επίσημα την κοινότητα σε δημόσιους ή άλλους χώρους. Παραδείγματα εκπροσώπησης της κοινότητάς μας περιλαμβάνουν τη χρήση μιας επίσημης διεύθυνσης ηλεκτρονικού ταχυδρομείου, τη δημοσίευση μέσω ενός επίσημου λογαριασμού μέσων κοινωνικής δικτύωσης ή την ενεργοποίηση ως διορισμένος εκπρόσωπος σε μια διαδικτυακή ή εκτός σύνδεσης εκδήλωση.
